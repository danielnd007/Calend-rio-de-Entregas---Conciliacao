Configuração com Google Sheets

Esta versão já funciona com os dados da planilha. Para atualizar automaticamente via Google Sheets, publique o Apps Script abaixo como Web App e cole a URL no campo do código JavaScript indicado no arquivo.

  1. Abra sua planilha no Google Sheets.
  2. Vá em Extensões → Apps Script.
  3. Cole o arquivo apps-script.gs.
  4. Implante como Web App com acesso “Qualquer pessoa com o link”.
  5. No arquivo script.js, preencha a variável GOOGLE_SHEETS_API_URL.
